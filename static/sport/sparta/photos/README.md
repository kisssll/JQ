# Фото для сайта

Можно разложить выбранные JPG-файлы по этим путям (имена важны):

- `club/hero.jpg` — главный экран;
- `club/story.jpg` — история и шапка галереи;
- `gyms/irk.jpg`, `gyms/fr.jpg`, `gyms/ssmu.jpg` — три зала;
- `coaches/dmitry.jpg`, `coaches/akim.jpg`, `coaches/bogdan.jpg` — тренеры;
- `gallery/01.jpg` … `gallery/06.jpg` — шесть кадров галереи.

Если фото ещё нет, сайт показывает тёмную карточку без сломанного изображения. Позднее отберём кадры и подписи вместе.
