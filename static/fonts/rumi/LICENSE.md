# Шрифты Руми

Оба начертания — SIL Open Font License 1.1, которая разрешает использование,
изменение и распространение, в том числе в коммерческом продукте, при условии
сохранения этого уведомления. Полные тексты рядом: `OFL-playfair-display.txt`,
`OFL-manrope.txt`.

- **Playfair Display** — Copyright 2017 The Playfair Display Project Authors
  (https://github.com/clauseggers/Playfair-Display). Переменный файл, веса 400–900,
  прямой и курсив.
- **Manrope** — Copyright 2019 The Manrope Project Authors
  (https://github.com/sharanda/manrope). Переменный файл, веса 200–800.

Файлы — подмножества (кириллица, латиница, расширения) в формате woff2, взяты
из раздачи Fontsource (npm `@fontsource-variable/*`, лицензия та же) и положены
к нам НАМЕРЕННО, а не подключены с fonts.gstatic.com: запрос за шрифтом с чужого
CDN отдаёт IP посетителя за границу, а в нашей Политике обработки персональных
данных прямо написано, что трансграничной передачи нет (152-ФЗ). Плюс в России
этот CDN периодически недоступен.

У Playfair нет кириллического «расширенного» подмножества — расширенная
кириллица (старославянские и редкие знаки) в сервисе не нужна.
